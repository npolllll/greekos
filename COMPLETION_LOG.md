# GreekOS — журнал доводки до production (13.11.2026)

Рабочая ветка: `claude/loving-bardeen-skp5nk`. Production деплоится из неё workflow «GreekOS deploy»
(Actions → Run workflow → ветка). Этот файл — checkpoint: что найдено, исправлено, проверено и что осталось.

## Инструменты, которыми проверяется production (без паролей в логах)

| Workflow | Что делает |
|---|---|
| GreekOS ops → `db-state` | только чтение: режим доступа, аккаунты по ролям (без e-mail), QA-пакеты, выпуски, расход, сбои |
| GreekOS ops → `llm-diagnose` | тот же запрос к Anthropic, что делает приложение, с точным ответом API (≈ 0,0003 $) |
| GreekOS ops → `acceptance` | приёмка на живом сайте: временные ученики по ссылке владельца, вход, изоляция, отключение, Speaking A1–B2, распознавание, скорость; временные аккаунты удаляются |
| GreekOS ops → `restore-test` | свежая копия → восстановление в чистую базу на раннере → сверка строк |
| GreekOS backup | еженедельно: зашифрованная копия (AES-256) + обязательная проверка восстановления |

Сессия владельца в приёмке открывается одноразовой ссылкой через service role — пароль владельца не используется.
