## 3. AI Speaking, голос и бюджет

- **Модель**: Claude Haiku 5.5 для разговора и проверки письма ($0,10 / $0,50 за млн токенов).
  Серверный fallback при отказе отправляется только моделям, которые его поддерживают (у Haiku его нет).
  Протокол Anthropic проверен контрактными тестами; **живые ответы Claude не получены**.
- **Голос**: Azure Speech F0 — распознавание el-GR, женский (Athina) и мужской (Nestoras) голоса.
  Протокол проверен контрактными тестами; при исчерпании квоты F0 разговор продолжается текстом с
  понятным сообщением.
- **Потоковый шлюз**: production-контейнер проверен по протоколам Azure и Anthropic. Перебивание,
  сохранение реплик, итоги и озвучка работают; собственная задержка шлюза ≈ 60 мс поверх паузы конца
  реплики 1,3 с (`verification/2026-11-04_gateway_container`). Без шлюза или при его сбое работает
  пошаговый режим.
- **Мобильный микрофон**: захват через AudioWorklet в 16 кГц, контекст создаётся по нажатию; запись
  на iPhone декодируется в WAV в браузере. На настоящем телефоне **не проверялось**.
- **Бюджет**: атомарный лимитер в базе — резерв до запроса, фактическая стоимость после, повтор не
  удваивает резерв, сбой освобождает резерв, незавершённый вызов считается по максимуму, новый месяц
  начинается с нуля, у каждого ученика свой дневной лимит. Integration-тест на 20 одновременных
  запросов подтверждает, что лимит не превышается. В админке видны расход, остаток, расход по сервисам
  и дата сброса. Расчётная стоимость — около 2 € в обычный месяц и 4,5–5 € в активный
  (`FINAL_DEPLOYMENT_GUIDE.md` §7).

## 5. Ограничения и решения владельца

- **Fly.io не имеет жёсткого потолка расходов.** Худший случай (≈ 4,6 € в месяц) заранее вычтен из
  лимита. Альтернатива с нулевой стоимостью — развёртывание без шлюза (пошаговый разговор).
- **Vercel Hobby — только для некоммерческого использования.** Pro ($20) выходит за бюджет.
- **У Supabase Free нет автоматических копий** — их заменяет еженедельный зашифрованный бэкап через
  GitHub Actions. Проект засыпает после 7 дней без активности.
- **Права ΠΕΓΠ**: 20 заданий и 2 пакета закрыты до разрешения правообладателя; раздел работает без них.
- Выпуск материалов, голосов и аудио — только решениями владельца в админке. Статусы «проверено
  человеком» система не ставит.
