## 2. AI Speaking на production (Anthropic Haiku 5.5, Azure Speech F0)

**Живой разговор на телефоне** (Pixel 7, микрофон — помеченный тестовый клип «Θέλω ένα κιλό ντομάτες, παρακαλώ»):

| Шаг | Время |
|---|---|
| Подключение и авторизация WebSocket (`/api/voice/stream`) | 0,7 с |

| Распознавание Azure: «Θέλω ένα κιλό ντομάτες παρακαλώ.», уверенность 0,75 | 0,9 с |
| Первое предложение ответа AI | 1,9 с |
| Ответ целиком | 3,1 с |

Ответ: «Ένα κιλό ντομάτες, βεβαίως. Οι ντομάτες τελείωσαν σήμερα. Έχουμε αγγούρια με δύο ευρώ το κιλό. Θέλετε;»
Пока он приходит текстом: голоса не утверждены. Задержку до начала звука (цель спецификации:
p50 ≤ 1,5 с) можно измерить только после утверждения голосов. Ожидаемо это около 3,5–4 с:
пауза VAD, затем распознавание по готовой реплике, затем ответ модели. Цель 1,5 с этой архитектурой
на бесплатных тарифах не достигается.

## 3. Доступ и безопасность (production)

- **Регистрация закрыта на четырёх уровнях:** страница, API (403), Supabase Auth (`signup_disabled`), база (`registration_mode = 'closed'`).
- **Ученика добавляет только владелец:** одноразовая ссылка; повторно она не срабатывает.
- **RLS:**
  - ученик не видит чужих строк (проверено на 8 таблицах) и служебных таблиц;
  - admin-API отвечает 403.
- **Отключение ученика:** открытая сессия получает 401, вход отклоняется.
- **Живой голос:**
  - только с адреса самого приложения, чужой Origin получает 403;
  - вход по одноразовому 60-секундному токену;
  - тестовый звук принимается только в предпросмотре владельца и помечается как тестовый.
- **Ключи и CSP:** ключи провайдеров есть только на сервере; CSP включает `wss://` самого приложения.
