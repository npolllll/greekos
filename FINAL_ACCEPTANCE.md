## 3. Доступ и безопасность (production)

- Регистрация закрыта: страница, API (403), Supabase Auth (`signup_disabled`), база (`check registration_mode = 'closed'`).
- Ученика добавляет только владелец: одноразовая ссылка → пароль; ссылка не срабатывает повторно; «Новая ссылка» для забытого пароля.
- RLS: ученик не видит чужих строк (8 таблиц) и служебных таблиц; admin-API — 403; `anon` без прав в `public`.
- Отключение: открытая сессия теряет доступ (401), вход отклонён.
- CSP и заголовки безопасности; ключи только на сервере.
