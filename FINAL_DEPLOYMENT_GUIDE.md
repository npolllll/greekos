# GreekOS — руководство по развёртыванию для владельца

Цель: запустить GreekOS для 4–5 учеников, ничего не программируя. Всё техническое делает workflow
**«GreekOS deploy»** в GitHub Actions. От вас нужны аккаунты, ключи (в секретах GitHub, не в чатах и
не в файлах), одно нажатие «Run workflow» и решения в админке.

Бюджет — **5 € в месяц цель, 10 € абсолютный максимум** на всё вместе. Как он соблюдается — в разделе 7.

---

## 1. Что будет работать и где

| Часть | Сервис и тариф | Стоимость |
|---|---|---|
| Сайт и сервер | Vercel **Hobby** (Frankfurt) | 0 € |
| База, вход, письма, файлы аудио | Supabase **Free** (Frankfurt) | 0 € |
| Отправка писем (подтверждение, сброс пароля) | Resend **Free**, 3 000 писем в месяц | 0 € + домен ≈ 10 € в год |
| AI-разговор и проверка письма | Anthropic API, модель **Claude Haiku 5.5** | ≈ 0,5–1,5 € в месяц (оценка ниже) |
| Распознавание речи и греческие голоса | Azure Speech **F0** (бесплатный) | 0 € (квота 0,5 млн символов и 5 часов в месяц) |
| Живой голосовой разговор | Fly.io, одна машина, спит между разговорами | ≈ 0,3 € в месяц, худший случай ≈ 4,6 € |
| Резервные копии | GitHub Actions, еженедельно, зашифровано | 0 € |

**Почему нужен Fly.io.** Живой разговор (микрофон ↔ голос с перебиванием) держит WebSocket-соединение
дольше, чем позволяет функция Vercel на бесплатном тарифе (обрыв через 300 секунд). Подробно —
`GreekOS_APP_HANDOFF_2026-10-29/app/docs/VOICE_GATEWAY_HOSTING.md`. Если Fly.io не нужен, при запуске
workflow выберите `voice_gateway = no`. Тогда AI-разговор работает в пошаговом режиме («записал —
получил ответ»), полностью на Vercel и без расходов на Fly.io.

## 2. Аккаунты (≈ 40 минут, один раз)

1. **Supabase** (supabase.com) → New project. Регион **Central EU (Frankfurt)**, тариф Free. Придумайте
   и сохраните **пароль базы**.
2. **Vercel** (vercel.com) → регистрация через GitHub, тариф **Hobby**. Hobby предназначен для личного
   некоммерческого использования. Если вы берёте с учеников деньги, нужен Pro ($20 в месяц), а это
   выходит за бюджет; тогда решать вам.
3. **Домен** для писем (если своего нет): любой регистратор, около 10 € в год.
4. **Resend** (resend.com) → Domains → Add domain → добавьте у регистратора DNS-записи SPF и DKIM,
   которые покажет Resend, и дождитесь статуса Verified. Без подтверждённого домена письма доходят
   только до вас.
5. **Anthropic** (console.anthropic.com):
   - Billing: купите **предоплаченные кредиты на $5** и **отключите автопополнение (auto-reload)**.
     Тогда больше этой суммы списать нельзя.
   - Если в консоли доступен лимит расходов рабочего пространства (spend limit), поставьте $5 в месяц.
   - API Keys → Create key.
6. **Azure** (portal.azure.com) → Create resource → **Speech** → регион **West Europe**, тариф
   **Free F0**. Нужна карта для подписки, но на F0 начисления невозможны. Рекомендую ещё
   Cost Management → Budgets → бюджет 1 € с уведомлением; это только уведомление, а не блокировка.
7. **Fly.io** (fly.io), если нужен живой разговор: регистрация с картой → Tokens → Create token.
   Жёсткого потолка расходов у Fly.io нет. Поэтому конфигурация ограничивает его одной машиной
   512 МБ, которая засыпает без разговоров, а худший случай (машина работает весь месяц, ≈ 4,6 €)
   заранее вычтен из лимита GreekOS.

## 3. Секреты в GitHub (≈ 15 минут)

GitHub → репозиторий → **Settings → Secrets and variables → Actions → New repository secret**.
Значения никуда больше не вставляйте.

| Секрет | Где взять |
|---|---|
| `SUPABASE_PROJECT_REF` | Supabase → Project Settings → General → Reference ID |
| `SUPABASE_DB_PASSWORD` | пароль базы из шага 2.1 |
| `SUPABASE_ACCESS_TOKEN` | supabase.com → Account → Access Tokens → Generate |
| `DATABASE_URL` | Supabase → Connect → **Session pooler** → строка с подставленным паролем |
| `NEXT_PUBLIC_SUPABASE_ANON_KEY` | Project Settings → API → anon / publishable key |
| `SUPABASE_SERVICE_ROLE_KEY` | Project Settings → API → service_role / secret key |
| `APP_URL` | адрес сайта: `https://greekos.vercel.app` или ваш домен (без `/` в конце) |
| `OWNER_EMAIL` | ваш e-mail — на него придёт первое приглашение владельца |
| `ANTHROPIC_API_KEY` | шаг 2.5 |
| `AZURE_SPEECH_KEY` | Azure → ваш Speech → Keys and Endpoint → KEY 1 |
| `SMTP_PASS` | Resend → API Keys → Create (это пароль SMTP) |
| `SMTP_SENDER` | адрес на подтверждённом домене, например `no-reply@ваш-домен` |
| `VERCEL_TOKEN` | vercel.com → Account Settings → Tokens → Create |
| `FLY_API_TOKEN` | шаг 2.7 (не нужен при `voice_gateway = no`) |
| `BACKUP_PASSPHRASE` | придумайте длинную фразу и сохраните её в менеджере паролей: без неё копию не открыть |

Регион Azure по умолчанию — `westeurope`. Если он другой, добавьте переменную (вкладка Variables)
`AZURE_SPEECH_REGION`.

## 4. Развёртывание («Deploy»)

GitHub → **Actions → GreekOS deploy → Run workflow**:

- `voice_gateway`: `yes` — живой разговор через Fly.io; `no` — пошаговый режим без Fly.io;
- `dry_run`: сначала можно поставить `1`, чтобы увидеть все шаги без изменений (секреты в логе скрыты);
  затем запустить с `0`.

Workflow (около 15–25 минут) делает всё сам, повторный запуск безопасен:

1. миграции базы, RLS, хранилище;
2. вход и письма: адрес сайта, перенаправления, SMTP Resend, шаблоны писем, запрет прямой регистрации
   в обход GreekOS, пароль от 10 символов;
3. загрузка учебного корпуса — 87 уроков, 1 856 заданий, сценарии, Real Greek, ΠΕΓΠ, экзамены;
4. приглашение владельцу на `OWNER_EMAIL`;
5. цифровой QA и записанные методические правки;
6. голоса Azure, предложения кастинга, генерация 142 аудио (на F0 бесплатно);
7. голосовой шлюз на Fly.io (если выбран);
8. переменные и производственная сборка в Vercel;
9. проверка сайта, шлюза и короткий живой разговор через шлюз временным тестовым аккаунтом.

Если GitHub Actions по какой-то причине не подходит, то же самое делает команда на своём компьютере
(нужны Node.js 22 и psql 17) из папки `GreekOS_APP_HANDOFF_2026-10-29/app`:

```bash
bash scripts/deploy-cloud.sh
```

## 5. Решения в админке (≈ 1 час, один раз)

Откройте письмо-приглашение → задайте пароль → «Админ».

1. **Политика выпуска** → прочитать и подписать.
2. **Контент** → откройте 13 новых текстов для чтения (ссылки — в
   `app/reports/v8/content-revisions/README.md`). Они написаны с помощью AI и проверены только
   автоматически.
3. **Выпуск** → пройти выборку (до 30 карточек) → «Принять решение о выпуске».
4. **Голоса и кастинг** → прослушать и утвердить голоса Azure (до этого тьютор отвечает текстом).
5. **Аудио** → прослушать файлы → «Записать условия провайдера» (ссылка на условия Azure) → выпустить.
   Задания на слух открываются только после этого.
6. **Ученики → Регистрация**: режим «по коду» или «открыта», мест — **5**. Ссылка для учеников:
   `APP_URL/register`.
7. **Права ΠΕΓΠ**: 20 заданий и 2 пакета остаются закрытыми, пока нет разрешения правообладателя.

## 6. Проверка после запуска (≈ 30 минут, сделайте сами)

- Зарегистрируйте тестового ученика с другого e-mail, получите письмо, задайте пароль, пройдите
  «С полного нуля» и одну попытку «Уже изучал(а)» с диагностикой. Лишний аккаунт затем удалите:
  Ученики → удалить данные.
- «Забыли пароль?» → письмо пришло.
- **На телефоне** (iPhone и Android): AI-разговор → разрешить микрофон → поговорить 2–3 минуты →
  перебить тьютора. Первый разговор после паузы может начаться через несколько секунд: шлюз просыпается.
- Админ → Провайдеры → «Проверить подключение» и блок расходов.
- GitHub → Actions → результат «GreekOS deploy» → артефакт `greekos-production-checks` с замером
  задержки разговора (p50/p95).

## 7. Расходы и гарантии

**Как соблюдается 10 €.** Каждый платный запрос к Anthropic (и к Azure, если когда-нибудь S0) сначала
резервирует в базе свою максимальную стоимость и только потом отправляется. Резерв — атомарная
операция под блокировкой месяца, повтор запроса не создаёт второго резерва. После ответа резерв
заменяется фактической стоимостью из ответа провайдера. Платные запросы прекращаются, когда расходы
месяца достигают **(10 € − 5,5 € фиксированных в худшем случае) × 0,8 = 3,60 €**. Без шлюза
предел — 7,20 €. Цены пересчитываются в евро по курсу 1 $ = 1 € с запасом на НДС 24 %.
Уроки, упражнения, прогресс, повторения и выпущенное аудио работают всегда, ограничиваются только
AI-разговор и AI-проверка письма. Ученик видит понятное сообщение; каждому ученику — не больше 0,50 €
в день. Расход, остаток и дата сброса (1-е число, 00:00 UTC) — Админ → Провайдеры.

| Сервис | Что ограничивает расходы | Гарантия |
|---|---|---|
| Anthropic | лимитер GreekOS + предоплата без автопополнения (+ spend limit) | жёсткая: больше предоплаты не списать |
| Azure Speech F0 | бесплатный тариф | жёсткая: начисления невозможны, при исчерпании квоты — текст вместо голоса |
| Supabase / Vercel Hobby / Resend Free | бесплатные тарифы | жёсткая: при превышении сервис ограничивается, а не выставляет счёт |
| Fly.io | одна машина 512 МБ, засыпает; худший случай вычтен из лимита | **не жёсткая**: у Fly.io нет потолка расходов. Альтернатива с нулевой стоимостью — `voice_gateway = no` |
| Домен | годовая оплата | фиксированная |

**Расчётная стоимость (не гарантия).** Допущения: 5 учеников, каждый в месяц — 12 AI-разговоров по
15 реплик, 40 письменных ответов с AI-проверкой; цены Claude Haiku 5.5 — $0,10 / $0,50 за млн токенов.

| Статья | Обычный месяц | Активный месяц (×4) |
|---|---|---|
| Anthropic (≈ 900 реплик + 200 проверок + итоги) | ≈ 0,6–0,8 € | ≈ 3 € (упрётся в лимит 3,60 €) |
| Azure Speech F0 (≈ 1,3 ч распознавания, ≈ 0,2 млн символов) | 0 € | 0 € (при исчерпании квоты — текст) |
| Fly.io (≈ 20 часов работы + спящий диск) | ≈ 0,3 € | ≈ 0,8 € |
| Домен | ≈ 0,85 € | ≈ 0,85 € |
| **Итого** | **≈ 2 €** | **≈ 4,5–5 €** |

Поднять лимиты или перейти на платные тарифы можно только вашим решением: переменные
`BUDGET_MONTHLY_EUR_MAX`, `AZURE_SPEECH_TIER=S0` и т. п. меняются в секретах, затем workflow
запускается заново. Сам GreekOS их не повышает.

## 8. Обслуживание

- **Резервная копия**: workflow «GreekOS backup» каждый понедельник; зашифрованные файлы лежат в
  Actions → артефакты (90 дней). Восстановление — `app/docs/OPERATIONS.md`.
- **Утечка ключа**: отзовите ключ у провайдера → обновите секрет в GitHub → перезапустите
  «GreekOS deploy».
- **Сбои**: Админ → Обзор → журнал ошибок; Админ → Провайдеры → проверка подключения.
- Supabase Free «засыпает» после 7 дней без активности. Ежедневная служебная задача GreekOS обращается
  к базе, поэтому при работе Vercel проект не простаивает; если сайт всё же уснул, нажмите «Restore»
  в панели Supabase.
