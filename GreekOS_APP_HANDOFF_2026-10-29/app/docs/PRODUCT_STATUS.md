# GreekOS — состояние продукта (04.11.2026)

Частная платформа изучения новогреческого для 4–5 учеников. Документ сверяет продукт с требованиями
задания «FINAL PRODUCT DELIVERY» и честно отделяет сделанное и проверенное от того, что зависит от
владельца или внешних поставщиков. Как принять сборку — [ACCEPTANCE.md](ACCEPTANCE.md), как выйти в
облако — [DEPLOYMENT.md](DEPLOYMENT.md).

> **12 критериев приёмки мастер-документа не сверены**: файла `GREEKOS_FINAL_PRODUCT_MANDATE.md` нет
> ни в проекте, ни в ветках репозитория, ни в подключённом Google Drive. GreekOS **не объявляется
> готовым** до сверки с этими критериями. Ниже — сверка с девятью требованиями из текста задания.

## Что сделано в этом цикле

- **Самостоятельная регистрация.** Владелец выбирает режим (закрыта / по коду / открыта) и число
  мест; код показывается один раз, хранится хеш. Заявку проверяет сервер (режим, код, места, 5
  попыток в час с IP), ответ одинаковый для существующих адресов. Аккаунт создаётся через письмо:
  ученик подтверждает адрес, задаёт пароль и проходит онбординг. Ссылка из письма сохраняет сессию в
  том же адресе браузера (раньше после подтверждения она терялась между `localhost` и `127.0.0.1`).
- **Путь опытного ученика проверен на настоящем корпусе без предпросмотра**: владелец проводит QA,
  выборку и выпуск; ученик проходит диагностику и попадает в маршрут A2, открывает урок, получает
  вердикты; всё созданное тестом удаляется.
- **Качественные облачные голоса.** Каталог Azure берёт родные греческие голоса (Athina, Nestoras) и
  многоязычные нейронные голоса с греческим (второй женский и второй мужской — для диалогов двух
  женщин и сцен на четверых). Многоязычные голоса говорят внутри `<lang xml:lang="el-GR">`.
  Предложения кастинга ранжируют голоса по качеству и заменяют локальные голоса разработки, не
  трогая утверждённые владельцем. Найден и исправлен дефект: облачные голоса считались «только для
  разработки», и форма записи условий провайдера не показывалась — выпуск облачного аудио был бы
  невозможен.
- **AI-разговор на Claude**: низкий effort для живого хода (у Opus 5.5 по умолчанию medium), кэш
  промпта сцены, запас `max_tokens` под всегда включённое мышление (локальный лимит 140 токенов
  обрезал бы ответ), серверный fallback при отказе классификатора — в том же потоке.
- **Выход в облако одним сценарием** `scripts/deploy-cloud.sh`: миграции, корпус, владелец, QA с
  записанными исправлениями, голоса Azure, переменные Vercel, развёртывание; повторный запуск
  пропускает сделанное; ответы и секреты — только в `.deploy/cloud.env` вне git. Проверен в режиме
  `DRY_RUN=1` (секреты замаскированы); в живом облаке не запускался.

Первый прогон e2e (`05_e2e.log`) дал 5 падений «page crashed» на разных страницах. Причина — не
приложение: диск сессии был заполнен (свободно 67 МБ), а Chromium держит общую память во временной
папке и не смог выделить её (`net::ERR_INSUFFICIENT_RESOURCES` уже на статических файлах). Место
освобождено (кэш сборки, отчёты тестов, рабочие файлы), `acceptance.sh` теперь направляет временные
файлы браузера в `/dev/shm`, если там есть место; полный повторный прогон — 41 / 41.

## Минимальный список действий владельца

1. **Аккаунты**: Supabase (проект в ЕС), Vercel, почтовый сервис SMTP (для писем регистрации).
2. **Ключи**: Anthropic API (AI-разговор и оценка), Azure Speech + регион (распознавание речи и
   голоса курса). Затем один раз: `bash scripts/deploy-cloud.sh` и четыре настройки в панели Supabase,
   которые сценарий печатает в конце (адрес сайта, шаблоны писем, SMTP, запрет прямой регистрации).
3. **Выпуск материалов**: Админ → Политика выпуска → подписать; Админ → Цифровой QA и выпуск →
   выборочная проверка → решение (готово 1 645 заданий).
4. **Голоса**: Админ → Голоса и кастинг → прослушать и утвердить предложенные голоса Azure;
   Админ → Аудио → «Сгенерировать пакет», прослушать, записать условия Azure — после этого 177
   заданий с аудио проходят допуск.
5. **Права** на 24 задания ΠΕΓΠ (20 в плане допуска заблокированы до решения).
6. По желанию: проверка носителем или преподавателем (статусы `HUMAN_*` система сама не ставит);
   на Mac — `npm run local:doctor` и `npm run speaking:latency`, если разговор нужен без облака.

## Честные ограничения

- Пока владелец не выпустил материалы, зарегистрированный ученик видит курс, алфавит и диагностику
  как «на проверке» — учиться по-настоящему он сможет после шага 3.
- Локальная модель (Gemma 4 E2B, CPU) ведёт сцену, но допускает грамматические неточности в репликах
  персонажа (в замере: «να εσάς παραδώσουμε»); качество уровня «полноценный разговор» ожидается с
  Claude — живой облачный вызов не выполнялся (ключей нет), проверены протокол и обработка ответа.
- Мужской голос MBROLA — только для разработки; облачные голоса проверены контрактным тестом
  против локального сервера с протоколом Azure/Google, не живым вызовом.
- Задержка на этом CPU выше цели пилота (конец речи → звук ≤ 1,5 с); на Mac не измерена.
