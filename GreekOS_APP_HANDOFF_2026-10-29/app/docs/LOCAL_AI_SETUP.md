# Локальные голос, распознавание и AI-собеседник (v6, разработка)

Всё ниже работает **без ключей, облачных аккаунтов и оплаты**. Это среда разработки и приёмки:
голоса, Whisper и локальная языковая модель не дают права выпускать материалы ученикам и не
заменяют проверку носителем. Проверено 30.10.2026 в Linux-контейнере (4 CPU, без GPU); на Mac с
Apple Silicon скорость будет заметно выше (Metal для модели, больше ядер для Whisper).

## Что запускается

| Процесс | Порт | Что делает | Команда |
|---|---|---|---|
| Next.js | 3210 | приложение | `npm run dev` |
| Supabase | 55321–55329 | БД, Auth, Storage, Realtime | `npx supabase start` |
| Сервис речи | 3312 | синтез (Coqui VITS «Ελένη», MBROLA «Γιώργος»/«Νίκος») + Whisper (sherpa-onnx) | `npm run local:speech` |
| Голосовой шлюз | 3311 | живой разговор: WebSocket, VAD, перебивание | `npm run voice:gateway` |
| Языковая модель | 3313 | OpenAI-совместимый сервер на node-llama-cpp (Gemma 4 E2B instruct, Q4_K_M; Metal на Mac) | `npm run local:llm` |

## Установка на Mac (Apple Silicon)

```bash
brew install python@3.11 espeak-ng node@22 bzip2
```

```bash
python3.11 -m venv ~/greekos-models/venv-coqui
```

```bash
~/greekos-models/venv-coqui/bin/pip install -r local-services/requirements.txt
```

```bash
npm run models:fetch
```

```bash
npm --prefix local-services/llm ci
```

`models:fetch` скачивает модели из `local-services/models.manifest.json` в `~/greekos-models`
(переопределяется `GREEKOS_MODELS`) и сверяет **каждый файл с SHA-256**; несовпадение не
принимается. Повторный запуск ничего не перекачивает. `node local-services/fetch-models.mjs --verify`
только проверяет установленное, `--all` добавляет необязательный Whisper base.

Мужские голоса MBROLA (gr2, gr1) — системный пакет. В Debian/Ubuntu: `apt-get install espeak-ng
mbrola mbrola-gr2 mbrola-gr1`. На macOS MBROLA нужно собрать из `github.com/numediart/MBROLA` и
положить базу `gr2` из `github.com/numediart/MBROLA-voices` в `/usr/local/share/mbrola/gr2/gr2`
(хеш — в манифесте). Лицензия MBROLA некоммерческая: эти голоса всегда `DEV_LOCAL_ONLY`. Без них
работает только женский голос; роли, требующие мужского голоса, честно остаются заблокированными.

## Переменные `.env.local`

```
APP_ENV=local
ASR_PROVIDER=local

LOCAL_ASR_URL=http://127.0.0.1:3312
LOCAL_ASR_STREAM_FINAL_MODEL=small
ALLOW_LOCAL_VOICE_PLAYBACK_FOR_DEV=1
VOICE_GATEWAY_SECRET=<32+ случайных символа>
NEXT_PUBLIC_VOICE_GATEWAY_URL=ws://127.0.0.1:3311
LLM_PROVIDER=openai_compatible
LLM_BASE_URL=http://127.0.0.1:3313
LLM_MODEL=gemma-4-E2B-it-Q4_K_M
LLM_TURN_TIMEOUT_MS=45000
```

`LLM_TURN_TIMEOUT_MS=45000` нужен только для CPU без GPU; на Mac с Metal хватит 25000.
Вместо `npm run local:llm` можно указать любой OpenAI-совместимый сервер (LM Studio, llama.cpp,
Ollama) с другой моделью: адаптер тот же.

## AI-собеседник: какая модель и почему ей можно говорить с учеником

Собеседник генерирует реплики потоково (сначала этап сцены, затем реплика; каждое готовое
предложение проходит проверку греческого — hunspell el_GR, алфавит, разметка, длина, согласование
числительных — и сразу озвучивается). Если модель не ответила вовремя или реплика не прошла
проверку, звучит авторская реплика сценария с пометкой «запасная». Разбор фразы ученика —
отдельный вызов после ответа: цитата должна быть дословной частью сказанного, исправление —
проходить проверку греческого; в интерфейсе это «подсказка AI», на освоение не влияет.

Локальная модель допускается к генерации **только после проверки на этой машине**:

```bash
npm run speaking:eval
```

25 случаев по реальным сценариям корпуса (ошибки ученика, русская речь, просьбы повторить, память
фактов, A0, экзамен B2 без подсказок, свободный разговор). Результат пишется в
`local-services/llm/qualification.json` и `reports/v6/speaking-eval/<модель>.md`; без записи
`passed: true` собеседник работает в сценарном режиме (и честно это показывает).

Проверено здесь (CPU, 4 ядра): **Gemma 4 E2B** — реплики без запасного сценария 100%, верный этап
100%, повтор ошибок 0, точность исправлений 75%, полнота 50%, кейс памяти не пройден; первое
предложение p50 ≈ 10 с, p95 ≈ 14 с. Qwen3-4B (v6) по-гречески не годилась.

**Важно для Gemma:** переиспользование KV-кэша в node-llama-cpp портило контекст этих моделей
(модель повторяла свою первую реплику и путала роли; не помогал и полный SWA-кэш). Сервер для
архитектур Gemma считает каждый запрос с чистой последовательности (`LOCAL_LLM_NO_REUSE`
переопределяет). На CPU это медленнее; с Metal — нет.

На Mac с ≥ 16 ГБ можно попробовать E4B, с ≥ 24 ГБ — 12B (одна сессия ≈ 10 ГБ, `LOCAL_LLM_SLOTS=1`):

```bash
node local-services/fetch-models.mjs --with=gemma-4-e4b-it-q4km
```

```bash
GREEKOS_LLM_MODEL=~/greekos-models/llm/gemma-4-E4B-it-Q4_K_M.gguf npm run local:llm
```

Затем `LLM_MODEL=gemma-4-E4B-it-Q4_K_M` в `.env.local` и снова `npm run speaking:eval`: модель
начнёт говорить с учеником только если пройдёт пороги.

## Ускорение на Apple Silicon

- Языковая модель: node-llama-cpp сам использует Metal (`/health` → `gpu: "metal"`).
- Whisper: ONNX Runtime с CoreML (`LOCAL_ASR_PROVIDER=coreml` по умолчанию на arm64 macOS; при
  ошибке загрузки — CPU). `/health` сервиса речи показывает `asr.providers_used`.
- Coqui: PyTorch MPS (`LOCAL_TTS_DEVICE`, по умолчанию `mps`, если доступен; при неподдерживаемой
  операции — CPU). `/health` → `tts_device`.

В этом контейнере (Linux, без GPU) эти пути не испытывались — после установки на Mac проверьте
`/health` и задержки на странице «Админ → Голоса».

## DEV-PREVIEW: реальные уроки до выпуска

Корпус закрыт до решения владельца. Чтобы пройти настоящие уроки локально, владелец открывает
тестовому аккаунту невыпущенный корпус (только `APP_ENV=local|test`, с журналом действий):
Админ → DEV-PREVIEW, или

```bash
npx tsx --conditions=react-server scripts/dev-preview.ts create-tester --owner owner@greekos.local --email maria.test@greekos.local --name "Мария (тест)" --days 14
```

Ответы тестера сохраняются по-настоящему, но с отметкой «не выпущено»; обычные ученики эти
материалы не видят. Отзыв — `revoke` или кнопка в админке.

## Аудио курса

```bash
npm run audio -- render-batch --force
```

```bash
npm run audio -- rescore
```

`render-batch` синтезирует все 142 задания по ролям, нормализует громкость, проводит технический QA
и проверку распознаванием каждого сегмента (Whisper turbo, фонетическое сравнение), при провале
сегмент перегенерируется. `rescore` пересчитывает вердикты по уже сохранённым расшифровкам после
изменения правил сравнения — без нового синтеза. Статус «Цифровая проверка пройдена» не означает
проверку носителем; выпуск — только решением владельца.

### Почему кусок Whisper не длиннее 15 секунд

sherpa-onnx ограничивает вывод Whisper примерно 6 токенами на секунду **входного** звука, а беглый
греческий синтез требует около 10 токенов в секунду. Без мер каждый длинный кусок терял хвост
(CER треков ΚΕΓ B2 ≈ 0,31). Сервис речи режет звук по паузам на куски ≤ 15 с и дополняет каждый
тишиной до окна 29 с — после этого те же треки проходят с CER ≈ 0,04.

## Что честно ограничено

- **Качество локального собеседника** измерено автоматическим набором (разметка разработчика по
  грамматике), а не носителем: Gemma 4 E2B проходит пороги, но ошибается — может повторить ошибку
  ученика в ответе, путает арифметику цен, полнота исправлений 50%. Поэтому всё, что она говорит о
  фразах ученика, — «подсказка AI», а итог разговора не меняет освоение компетенций.
- **Задержка на CPU**: первое предложение ответа ≈ 10 с (p50) без параллельной нагрузки, ход
  целиком ≈ 12–13 с; распознавание реплики ≈ 6–7 с; при параллельном рендере аудио ход может не
  уложиться в таймаут — тогда звучит помеченная запасная реплика. Цели пилота (p50 ≤ 1,5 с) на этом
  CPU недостижимы; на Mac с Metal нужно измерить заново.
- **Один женский голос**: Coqui `el/cv/vits` и Piper `rapunzelina` обучены на одном наборе CSS10 —
  это одна и та же дикторша. Диалоги двух женских персонажей (5 заданий) нельзя озвучить разными
  голосами — они заблокированы с причиной; готовую запись можно импортировать в админке («Импорт
  готового файла») — она пройдёт тот же цифровой QA.
- **Мужской голос** есть только MBROLA (некоммерческий, дифонный): к выпуску недопустим, и около 40%
  его сегментов не проходят сверку распознаванием. Для выпуска нужен лицензированный мужской голос.
- **Уверенность распознавания**: sherpa-onnx Whisper не отдаёт вероятности, поэтому каждая живая
  реплика подтверждается учеником («Это вы сказали?»). Это не оценка произношения.
