# Приёмка GreekOS на своей машине

Всё работает локально: без облака, ключей и оплаты. Ниже — как развернуть сборку, что проверить
руками и чем подтвердить измерения на Mac. Что пока не может быть принято (права, голоса, проверка
носителем, облако), перечислено в конце и в [STATUS_V8.md](STATUS_V8.md).

## 1. Развернуть (один раз, ~30–60 мин, ≈ 12 ГБ на диске)

Нужны Node ≥ 22.12, Docker, Python 3.11, `espeak-ng` и `mbrola` (мужской голос для разработки).

```bash
git clone <репозиторий> && cd GreekOS_APP_HANDOFF_2026-10-29/app
```

```bash
bash scripts/setup-local.sh you@example.com "Ваше имя" tester@example.com
```

Скрипт идемпотентен: зависимости, Supabase в Docker, импорт корпуса, владелец, модели с проверкой
SHA-256, сервис речи и модель, кастинг, аудио из комплекта `../audio_bundle`, цифровой QA с
исправлениями-ревизиями, тестовый ученик DEV-PREVIEW. Пароли — в `.local-credentials/`.

Запуск после установки (отдельные терминалы):

```bash
npm run voice:gateway
```

```bash
npm run dev
```

Production-вариант вместо `dev`: `npm run build && npm run start` (порт 3210).

## 2. Проверить, что реально включено

```bash
npm run local:doctor
```

На Mac с Apple Silicon ожидается: модель — `metal`, KV-кэш переиспользуется, flash attention вкл,
ASR — `coreml`, TTS — `mps`, квалификация модели пройдена. Знак ✗ означает, что ускорение не
включилось, — сервисы при этом работают на CPU.

## 3. Полный автоматический прогон

```bash
bash scripts/acceptance.sh
```

Типы, линт, unit, интеграция (живой Supabase, Whisper, Coqui, шлюз), e2e (путь ученика, все 21 тип
заданий корпуса в своих плеерах — «кто это сказал?» до выпуска звука честно показывает «нет аудио»,
его оценивание проверяет unit-тест по всем 1 843 заданиям; уроки A0–B2, экзамен, админка, телефон 390/320 px, живой голос с поддельным
микрофоном), правила курса на корпусе, задержка AI-собеседника, план допуска, production-сборка.
Итог — `../verification/<дата>_acceptance/SUMMARY.txt` (0 = успешно) и журналы шагов.
E2E также проверяет самостоятельную регистрацию (письмо из локального Mailpit) и главный путь
«владелец выпускает → ученик с опытом проходит диагностику → маршрут → урок» на настоящем корпусе.

Если e2e пишет `page crashed` / `Target crashed`, проверьте свободное место на диске: Chromium держит
общую память во временной папке, и на почти полном диске вкладки падают. На Linux скрипт сам
использует `/dev/shm`, если там есть место; вручную — `TMPDIR=/dev/shm npm run test:e2e`.

## 4. Пройти руками (30–40 мин)

Ученик (тестовый аккаунт из `.local-credentials/tester.json`):

1. Главная → «Алфавит и звуки»: буква, звук, тренажёр.
2. Урок U-A1-001: теория → фразы → практика; неверный ответ → «Почему так?» → перенос → верный ответ.
3. «AI-разговор» → «Кафе» → «Голосом»: скажите «Θέλω ένα καφέ και ένα νερό». Ожидается: реакция
   персонажа в течение нескольких секунд (на Mac — около секунды), под вашей фразой — исправление
   «έναν καφέ» с пометкой «Правило курса»; перебейте ответ голосом — он остановится; «Завершить» —
   итог с главными исправлениями и их озвучкой.
4. «Экзамен КЕГ B2» → чтение → «Практика без таймера» → ответ → «Сдать» → результат.
5. «Мои ошибки»: ошибки сгруппированы по заданиям, видно ваш ответ и верный вариант.
6. Телефон (или узкое окно 390 px): главная, маршрут, урок, разговор — без обрезанного текста.

Владелец (`.local-credentials/owner.txt`):

1. Админка → «Цифровой QA»: запустить проверку, открыть замечания.
2. «Выпуск»: выбрать урок — без подписанной политики решение недоступно (так и задумано).
3. «Аудио»: прослушать запись, статусы проверки, импорт готового файла по заданию.
4. «Голоса и кастинг»: предложения по ролям, аналитика AI-собеседника (реплики AI / запасные, время).
5. «Ученики»: карточка ученика, роль совладельца (с подтверждением), сброс сессий.

## 5. Измерить на Mac (для решения о пилоте)

```bash
npm run speaking:latency
```

Отчёт: `reports/v7/speaking-latency/<модель>-SC05.md` — время до первого проверенного предложения
каждого хода и машина. По желанию — переквалифицировать модель на Mac и попробовать E4B:

```bash
npm run speaking:eval
```

## Что требует вашего решения или внешнего поставщика

- Подписать цифровую политику выпуска и принять решение по пакету QA: до этого ученикам не выпущено
  ничего (план допуска: 1 645 заданий готовы к решению, `reports/v7/admission/ADMISSION_PLAN.md`).
- Права 24 заданий ΠΕΓΠ (нет блока лицензии).
- Лицензированные голоса: второй женский (8 диалоговых заданий заблокированы) и мужской (MBROLA —
  только для разработки; 54 записи с ним на разборе). Можно импортировать готовые записи по заданиям.
- Прослушать аудио, записать условия поставщика голоса, утвердить кастинг.
- Проверка носителем/преподавателем (статусы `HUMAN_*` система не присваивает).
- Облако (Supabase Cloud, Vercel, облачные LLM/ASR/TTS) — отдельный этап; адаптеры облачных
  провайдеров реализованы и проверены контрактными тестами против локальных серверов с теми же
  протоколами, живой облачный вызов не выполнялся.
