# GreekOS — руководство владельца

Для того, кто ведёт курс для 4–5 учеников. Технические подробности — в `DEPLOYMENT.md` (развёртывание)
и `OPERATIONS.md` (эксплуатация); текущее состояние и что осталось — в `PRODUCT_STATUS.md`.

## 1. Вход

Адрес — https://greekos-course.vercel.app. Вход по e-mail и паролю; админ-панель — пункт «Админ-панель» в
меню (видна только владельцу). **Смена пароля:** Настройки → «Пароль и вход»: текущий пароль, новый (не
короче 12 символов) — все остальные устройства сразу выходят из аккаунта, это устройство остаётся в системе.
Забыли пароль владельца: GitHub → Actions → «Reset GreekOS owner password» (новый пароль берётся из секрета
`GREEKOS_OWNER_NEW_PASSWORD`).

## 2. Первый запуск: два личных действия

Всё остальное уже сделано AI-редактором GreekOS по поручению, которое вы подписываете в шаге 1. Это не человек и не преподаватель. AI-редактор:
- проверил корпус;
- выбрал голоса;
- перезаписал ошибочные аудио;
- проверил каждую запись двумя распознавателями.

Каждое его действие записано от его имени, а не от вашего, и отменяется в админке.

1. **Политика выпуска** (Админ → «Политика выпуска»). Прочитайте риски, отметьте каждый и поставьте флажок поручения AI-редактору. Введите «ПРИНИМАЮ РИСК» и подпишите.
   - Это ваше принятие риска: материалы открываются по цифровой проверке и AI-проверке выборки, без проверки преподавателем.
   - Сразу после подписи AI-редактор выпускает уроки, задания, сценарии, Real Greek и ΠΕΓΠ, если у них вердикт PASS последнего полного QA и выборка проверена.
   - Отменить можно там же. История попыток учеников сохраняется.
2. **Условия провайдера голоса** (Админ → «Аудио» → «Условия провайдера голоса — ваше решение»). Откройте условия Microsoft Azure AI Speech (ссылка в карточке). Вставьте адрес, укажите дату, отметьте подтверждение и сохраните.
   - Это ваша запись о том, что синтезированную речь Azure можно показывать ученикам.
   - После неё AI-редактор выпускает аудио, прошедшее проверку, и открываются задания на слух.

Проверить или изменить решения AI-редактора можно здесь:
- голоса — Админ → «Голоса и кастинг», в колонке статуса указано «выбран AI-редактором» и причина;
- аудио — Админ → «Аудио», в истории файла;
- выпуск — Админ → «Выпуск».

Подробности: `docs/CONTENT_REVIEW_2026-11-15.md` и `docs/AUDIO_AND_VOICE_REVIEW_2026-11-15.md`.

## 3. Ученики

- **Регистрация закрыта.** Аккаунт ученику создаёте только вы: Админ → Ученики → «Добавить ученика» → имя,
  e-mail, опыт → «Одноразовая ссылка». Скопируйте ссылку и отправьте ученику в любом мессенджере: по ней он
  задаёт пароль и проходит онбординг («с нуля» — алфавит; «уже изучал(а)» — диагностика → свой маршрут).
  Почта не нужна. Ссылка срабатывает один раз.
- **Забыл пароль:** карточка ученика → «Новая ссылка» → отправьте её ученику; по ней он задаст новый пароль.
- **Места:** «Доступ учеников» — сколько учеников можно добавить (защита от лишних аккаунтов).
- **Карточка ученика**: цель и самооценка, маршрут, пройденные уроки, ошибки, отсроченные проверки
  D1–D28, навыки по доказательствам, разговоры. Действия: изменить маршрут, отключить (вход и доступ к
  данным блокируются сразу), включить, экспорт данных, удаление данных.
- **Проверка ответов** (Админ → «Проверка ответов»): открытые ответы и оспаривания, которые
  автоматика не оценила окончательно.

## 4. Каждую неделю (10 минут)

- Админ → «Обзор»: активность учеников и **журнал ошибок сервера** (в том числе ошибки голосового
  шлюза); пусто — хорошо.
- Админ → «Провайдеры»: расход платных API за месяц в евро, остаток до лимита, расход по сервисам и дата сброса. При исчерпании лимита AI-разговор и AI-проверка вежливо отказывают до следующего месяца, а уроки, упражнения и аудио работают (бюджет — `FINAL_DEPLOYMENT_GUIDE.md` §7).
  данные не теряются. Лимиты задаются и в консолях Anthropic и Azure.
- Админ → «Голоса и кастинг»: задержка живого разговора (p50/p95 «конец речи → звук»).
- Резервная копия делается сама каждый понедельник (GitHub → Actions → «GreekOS backup»): зашифрованный
  дамп + обязательная проверка восстановления в чистую базу (число строк каждой таблицы должно совпасть).
  Зелёный значок — копия есть и восстанавливается. Запустить вручную: «Run workflow».

## 5. Если что-то не работает

| Симптом | Что сделать |
|---|---|
| Ученик не может войти | Карточка ученика → «Новая ссылка» (пароль задаётся заново); отключённый ученик — «Включить» |
| В разговоре «запасная реплика сценария» | Админ → «Провайдеры» → «Последние сбои»: там точный ответ сервиса (лимит, ошибка, превышение времени) |
| «Сервис распознавания или синтеза речи недоступен» | Состояние Azure; ключ и регион в Vercel; лимиты Azure F0 (5 ч распознавания, 0,5 млн символов синтеза в месяц) |
| AI отвечает «лимит исчерпан» | Админ → «Провайдеры»: расход; при необходимости поднять лимит переменной и сделать redeploy |
| Ошибочно выпущен материал | Админ → «Контент» → «Отозвать» (или откат решения в «Выпуск») |
| Утечка ключа | Отозвать ключ у провайдера → новый ключ в секретах GitHub → «GreekOS deploy» (подробно — `OPERATIONS.md`, «Инциденты») |

## 6. Что система не делает сама

Не подписывает политику (принятие риска), не записывает условия провайдеров, не открывает материалы с
неурегулированными правами, не ставит статусы «проверено человеком». Голоса, выборку и выпуск PASS-материалов
AI-редактор делает только по вашему поручению в подписанной политике и только от своего имени. (14.11.2026: у 20 заданий ΠΕΓΠ записано происхождение — это собственные
тексты GreekOS; задания с портретами исторических лиц заменены текстовыми, официальный банк вопросов не
перепубликуется.)

## 7. Обновления приложения

Production публикуется только workflow «GreekOS deploy» из ветки `main` (GitHub → Actions → «GreekOS
deploy» → Run workflow). Автоматические сборки Vercel из Git выключены (`vercel.json`), чтобы push в
любую ветку не мог подменить production. Развёртывание само останавливается, если коммит не содержит
того, что уже работает в production (защита от отката); `/api/health` показывает развёрнутый коммит.
Осознанный откат — GitHub → Actions → «GreekOS ops» → задача `vercel-rollback`.
