# GreekOS — руководство владельца

Для того, кто ведёт курс для 4–5 учеников. Технические подробности — в `DEPLOYMENT.md` (развёртывание)
и `OPERATIONS.md` (эксплуатация); текущее состояние и что осталось — в `PRODUCT_STATUS.md`.

## 1. Вход

Адрес — тот, что напечатал `scripts/deploy-cloud.sh` (`APP_URL`). Первое письмо-приглашение приходит
на `OWNER_EMAIL`: ссылка → задать пароль (≥ 10 символов). Дальше — обычный вход; «Забыли пароль?»
присылает письмо для смены пароля. Админ-панель — пункт «Админ» в меню (видна только владельцу).

## 2. Первый запуск: пять решений

Сделайте один раз, по порядку. Ничего из этого система не делает за вас.

1. **Политика выпуска** (Админ → «Политика выпуска»). Прочитайте и подпишите цифровую политику:
   материалы открываются ученикам по результатам автоматической проверки и вашей выборки, без
   проверки преподавателем. Пока политика не подписана, ученики видят уроки «на проверке».
2. **Содержание** (Админ → «Контент» → «Уроки A1–B2»). В колонке «Цифровая проверка» у каждого
   урока итог; на странице урока — карточка «Содержательная проверка урока»: полнота, греческий,
   ключи, объяснения ошибок, уровень CEFR, логика, теория, права, аудио. Сводка по всем урокам —
   `reports/v8/lesson-qa/README.md` (обновить: `npm run qa:lessons`). Это автоматическая проверка,
   не проверка преподавателем — в карточке так и написано.
3. **Выпуск** (Админ → «Выпуск»). Система предлагает выборку (не больше 30 карточек разных типов).
   Откройте каждую, отметьте «OK» или «Замечание», затем «Принять решение о выпуске» — открывается
   весь допустимый пакет: уроки, задания, сценарии разговора, Real Greek, пакеты ΠΕΓΠ. Задание с
   вердиктом FAIL или неснятым блокирующим замечанием не откроется ни при каком решении.
   Отменить — кнопкой отката решения там же (история попыток учеников сохраняется).
4. **Голоса** (Админ → «Голоса и кастинг»). Прослушайте образец каждого голоса Azure, утвердите
   подходящие, проверьте назначение ролей (тьютор, рассказчик, персонажи диалогов) и утвердите роли.
   До утверждения тьютор в разговоре отвечает только текстом. Голоса MBROLA и голоса macOS — только
   для разработки: утвердить их в рабочей версии нельзя.
5. **Аудио** (Админ → «Аудио»). Прослушайте записи (каждая уже прошла распознавание и сверку со
   сценарием), отметьте замечания, затем «Записать условия провайдера» (ссылка на условия Azure и дата
   проверки) и выпустите. Пока аудио не выпущено, задания на слух закрыты, а урок отмечается
   «Пройден, кроме аудио».

## 3. Ученики

- **Регистрация** (Админ → «Ученики» → «Регистрация учеников»): режим «закрыта / по коду / открыта»
  и число мест. Ссылка для учеников: `<адрес>/register`. Ученик подтверждает e-mail по письму, задаёт
  пароль и выбирает «с нуля» (начинает с алфавита) или «уже изучал(а)» (диагностика → свой маршрут).
- **Приглашение вручную**: «Пригласить ученика» — письмо или ссылка для ручной передачи.
- **Карточка ученика**: цель и самооценка, маршрут, пройденные уроки, ошибки, отсроченные проверки
  D1–D28, навыки по доказательствам, разговоры. Действия: изменить маршрут, отключить (вход
  блокируется сразу), включить, экспорт данных, удаление данных.
- **Проверка ответов** (Админ → «Проверка ответов»): открытые ответы и оспаривания, которые
  автоматика не оценила окончательно.

## 4. Каждую неделю (10 минут)

- Админ → «Обзор»: активность учеников и **журнал ошибок сервера** (в том числе ошибки голосового
  шлюза); пусто — хорошо.
- Админ → «Провайдеры»: расход за сутки и месяц против лимитов (`BUDGET_MONTHLY_USD`, по умолчанию
  40 $; `BUDGET_DAILY_USD_PER_USER`, 1,5 $). При превышении AI-функции вежливо отказывают, учебные
  данные не теряются. Лимиты задаются и в консолях Anthropic и Azure.
- Админ → «Голоса и кастинг»: задержка живого разговора (p50/p95 «конец речи → звук»).
- Резервная копия: `DATABASE_URL=<строка Session pooler> bash scripts/backup-db.sh` — и перед любой
  миграцией (или ежедневные копии Supabase Pro).

## 5. Если что-то не работает

| Симптом | Что сделать |
|---|---|
| Ученику не пришло письмо | Папка «Спам»; в Resend → Emails видно, ушло ли письмо; домен отправителя должен быть подтверждён |
| Разговор «Голосовой канал недоступен» | `https://<шлюз>.fly.dev/health`; `fly logs --app <шлюз>`; при сбое приложение само предлагает пошаговый режим (запись → проверка → ответ) |
| «Сервис распознавания или синтеза речи недоступен» | Состояние Azure; ключ и регион в Fly и Vercel; лимиты Azure |
| AI отвечает «лимит исчерпан» | Админ → «Провайдеры»: расход; при необходимости поднять лимит переменной и сделать redeploy |
| Ошибочно выпущен материал | Админ → «Контент» → «Отозвать» (или откат решения в «Выпуск») |
| Утечка ключа | Отозвать ключ у провайдера → новый ключ в Vercel и `fly secrets set` → redeploy (подробно — `OPERATIONS.md`, «Инциденты») |

## 6. Что система не делает сама

Не подписывает политику, не утверждает голоса, не записывает условия провайдеров, не открывает
материалы с неурегулированными правами (20 заданий и 2 пакета ΠΕΓΠ ждут разрешения правообладателя),
не ставит статусы «проверено человеком». Все эти решения — ваши и остаются в журнале аудита.
