# Статус GreekOS — 03.11.2026 (v6.1: доработка после приёмки v6)

Продолжение v6 в той же ветке и кодовой базе. Всё ниже проверено в работающем приложении в
локальной среде (Linux-контейнер, 4 CPU, без GPU, Supabase в Docker). Облако, платные AI и ключи не
подключались. Где проверить нельзя без внешнего провайдера или Mac — так и написано.

## Что изменилось по замечаниям

### 1. AI Speaking: генеративный собеседник вместо сценарного механизма

- **Новый движок разговора** (`src/lib/speaking/conversation.ts`): модель ведёт роль персонажа
  сцены (роль, регистр «ты/вы», пол — для всех 48 сценариев), реагирует на слова ученика, держит
  этапы сцены как педагогическую рамку, помнит факты разговора (цены, время, договорённости),
  ведёт свободный разговор с собственными вопросами.
- **Потоковый голос**: модель пишет JSON, где первым идёт этап, затем реплика; каждое готовое
  предложение проходит проверку греческого (hunspell el_GR, алфавит, разметка, длина, согласование
  числительных) и **сразу озвучивается** шлюзом, пока модель дописывает остальное.
- **Перебивание** останавливает генерацию; сохраняется только то, что прозвучало.
- **Разбор фразы ученика** — сначала детерминированные правила курса (согласование числительных:
  «ένα καφέ → έναν καφέ», «τρεις ευρώ → τρία ευρώ»), помеченные «Правило курса (проверка без AI)»;
  затем отдельный вызов модели после ответа: цитата обязана быть дословной частью сказанного,
  исправление — проходить проверку; ложные и «вариантные» исправления (τη/την, ударение)
  отбрасываются. Без квалифицированной модели работают только правила. В итоге разговора — 2–3
  главных пункта с озвучкой правильной формы; итог ждёт (до 25 с) разборы, которые ещё в работе.
- **Модель не повторяет ошибку ученика**: проверка реплики исправляет «ένα» перед частыми
  существительными мужского рода в винительном («έναν καφέ») — найдено на живой записи сцены «Кафе».
- **Честные пометки**: у каждой реплики собеседника видно, кто её сказал — AI, авторская реплика
  (сценарный режим) или запасная реплика (AI не ответил вовремя / реплика не прошла проверку).
- **Квалификация модели вместо доверия**: локальная модель говорит с учеником, только если прошла
  набор `npm run speaking:eval` (25 случаев по реальным сценариям). Результат —
  `local-services/llm/qualification.json`, отчёт — `reports/v6/speaking-eval/`.
- **Модель**: Gemma 4 E2B (Q4_K_M, OCI-артефакт с SHA-256). Qwen3-4B из v6 по-гречески не годилась.
- **Найден и исправлен дефект**: переиспользование KV-кэша в node-llama-cpp портило контекст Gemma
  (модель повторяла свою первую реплику и путала роли) — для архитектур Gemma каждый запрос считается
  с чистой последовательности. После исправления E2B прошла пороги (см. таблицу ниже).
- **Контракты провайдеров**: потоковые адаптеры OpenAI-совместимого API и Anthropic Messages
  проверены контрактными тестами против локальных серверов с теми же протоколами (не живой
  провайдер). Подключение облака — переменные окружения, без изменения кода.
- **Apple Silicon**: Metal для модели (node-llama-cpp), CoreML для Whisper, MPS для Coqui, с откатом
  на CPU и отчётом в `/health`. В этом контейнере не испытано.

Проверка `npm run speaking:eval` (25 случаев, разметка разработчика; не экспертная оценка):

дефектом KV-кэша недействительны (помечены в `qualification.json`).

### 2. Аудио

- **Окончания реплик Coqui**: 43 из 45 «возможных обрывов» были вопросами, которые несущая фраза
  обрывала на гласной. Пауза после целевой фразы сохраняет естественный спад; синтез 2.2. На
  перерендеренных файлах — 0 обрывов.
- **Кастинг**: имена по окончанию (Νικόλας, Τάσος, Λέων / Έλλη, Ρένα, Ιώ), существительные общего
  рода без указания в тексте — голос, контрастный собеседнику. Это предложения: для выпуска кастинг
  утверждает владелец. 14 ранее заблокированных заданий получили файлы.
- **Импорт готового файла** по заданию (студия, актёр, внешний синтез): тот же цифровой QA, права —
  «ожидают условий», пока владелец их не запишет.
- **Объективно заблокировано**: 5 диалогов двух женских персонажей — второго женского голоса нет
  (Coqui и Piper обучены на одной дикторше CSS10). Мужской голос — только MBROLA (некоммерческий).

### 4. Дизайн

- **Сцена Салоник за интерфейсом не загружалась**: прокси авторизации перенаправлял `/scene/*.webp`
  на вход. Исправлено; детальная иллюстрация (собственная SVG → WebP) мягко размыта за более
  прозрачной стеклянной оболочкой, как в референсе; в уроках и экзаменах фон уходит на второй план.
- Новые элементы разговора (живая реплика во время генерации, карточки разбора фраз) — в той же
  стеклянной системе, с reduced motion.
- **Телефон**: верхняя плашка статуса больше не обрезает «локальная среда…» и переключатель
  анимаций; в маршруте название урока занимает всю строку, бейджи — под ним; шаги уровней —
  кольцо над подписью. Проверено на 360 и 390 px без горизонтальной прокрутки.
- Записи сцен (`reports/v6/captures`): S1 путь ученика, S4 AI-разговор (генерация, правило курса,
  итог), S7 владелец (QA, аудио, аналитика AI, роль совладельца), S9 телефон.

## Что требует владельца или внешнего провайдера (код готов)

1. Подписать цифровую политику и принять решение по пакету QA — без этого ничего не выпускается
   (план допуска показывает, что станет доступно).
2. Права 24 заданий ΠΕΓΠ (нет блока лицензии) — решение владельца.
3. Лицензированные голоса: второй женский и мужской (для выпуска). Пока — импорт готовых файлов или
   облачный TTS по ключу.
4. Прослушивание аудио, условия провайдера голоса, утверждение кастинга.
5. Проверка носителем/преподавателем (статусы `HUMAN_*` система не присваивает).
6. Mac: измерить задержки с Metal/CoreML/MPS и при желании прогнать `npm run speaking:eval` для E4B/12B.
7. Облако (Supabase Cloud, Vercel, облачные LLM/ASR/TTS) — NOT_TESTED, следующий этап.

## Честные ограничения

- Качество локального собеседника измерено автоматическим набором (разметка разработчика), а не
  носителем. Модель ошибается; поэтому её разбор — «подсказка AI», итог не меняет освоение.
- Задержки на этом CPU далеки от целей пилота (p50 ≤ 1,5 с); на Mac нужно измерить.
- MBROLA-голос плохо распознаётся Whisper (≈40% сегментов) и к выпуску недопустим.
