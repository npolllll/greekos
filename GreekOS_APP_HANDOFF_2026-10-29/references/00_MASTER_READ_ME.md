# GreekOS — единственная итоговая директива для локальной разработки

1. Распакуйте этот пакет **в корень уже существующей папки приложения GreekOS**, не создавая новый проект. Файл `MASTER_EXECUTION_DIRECTIVE.md` и каталог `references/` должны оказаться внутри действующего проекта.
2. Откройте ту же локальную папку через **Claude Desktop → Code → Local**.
3. Отправьте Claude текст: `Выполни MASTER_EXECUTION_DIRECTIVE.md как единое обязательное финальное задание, используй references/Glassy_Dashboard_V4_reference.mp4 и все уже имеющиеся документы/данные проекта. Не начинай с нового аудита: сразу продолжай завершение реальных функций и редизайн. Не запрашивай API-ключи и облачные аккаунты; сейчас работаем локально.`
4. Позже владелец может передать детализированный собственный GreekOS UI-макет; он уточняет точную визуальную реализацию по правилам приоритета основного документа.

**Примечание:** пакет содержит только новую мастер-директиву и присланный владельцем визуальный ролик. Он не заменяет существующие исходники, учебный корпус и предшествующие voice-спецификации.
